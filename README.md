# Колесо вкусов кофе

Интерактивное колесо вкусов кофе (веб-компонент `<flavor-wheel>` в `flavor-wheel/`).

- `index.html` — страница с колесом
- `flavor-wheel/` — компонент, данные, шрифты
- `PROMPT.md` — исходная спецификация
- `TASK.md` — текущее задание на доработку
- `screenshots/` — референсные скриншоты
- `tools/`, `_build_flavor_data.py` — сборка данных
